# EcoRoute 🌱

EcoRoute is a smart travel planner that helps users choose routes based on time, cost, and carbon footprint.

## Features
- Real-time route suggestions
- Carbon footprint estimation
- Cost analysis (fuel, tolls, tickets)
- Gamified eco incentives

## Tech Stack
- React.js + Tailwind CSS
- Node.js + Express
- MongoDB
- Google Maps API, Carbon Interface API
